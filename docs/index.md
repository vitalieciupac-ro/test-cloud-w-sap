## What You'll Build

This training guides you through UiPath's Test Cloud, from planning and designing tests in Test Manager, to automating them in Studio, to running them at scale through Orchestrator — with agentic AI woven in at every step:

1. **Test Manager & Agentic Testing Fundamentals** — Get familiar with Test Manager, create your own project, and see how Agentic Testing (Autopilot for Testers and custom AI agents) fits into the testing lifecycle.
2. **Building Automated Tests in Studio** — Go from a manual test case to a fully automated one: data-driven testing, Orchestrator, publishing, and executing test sets.

## Learning Objectives

By the end of this course, you will:

✅ Create a test project in Test Manager and explore its structure

✅ Design test cases and organize them into executable test sets

✅ Automate a manual test case in Studio using the Object Repository and data-driven testing

✅ Publish automated tests to Orchestrator and execute them end-to-end

✅ Use Agentic features (Autopilot for Testers) to accelerate test design and execution

**Real deliverable:** By day's end, you'll have **automated and executed a complete test set** for an SAP purchase order check in SAP GUI — from test design in Test Manager through execution in Orchestrator.

## Technical Prerequisites

Participants are required to have UiPath Studio and UiPath Assistant installed on their systems, along with Microsoft Excel and SAP GUI for Windows connected to an SAP system. Access to the Automation Cloud environment, along with the necessary UiPath services and licenses, will be provided to ensure a seamless experience during the session.

### Pre-Training Setup Checklist

Before attending the training, ensure you have completed the following:

✅ UiPath Studio, version 25.10.17 — Community or Enterprise, licensed and opened at least once

✅ UiPath Assistant running on your system

✅ Access to Automation Cloud environment verified

✅ Microsoft Excel installed — used for the data-driven testing exercise

✅ Access to an SAP system — your organization's system or an SAP trial

✅ SAP GUI for Windows (SAP Logon) installed and connected to your SAP system

!!! warning "SAP access is a separate license"
    UiPath cannot provide an SAP environment of any kind. SAP is a licensed product, and access to any SAP system is granted by **SAP** under a separate commercial agreement, not by UiPath. UiPath automates SAP but does not resell or grant access to it, so this training cannot include an SAP environment. Use your organization's SAP system, or an SAP-provided trial.

!!! quote "Here's something worth holding onto as you work through this training"
    Agentic testing doesn't replace testers — it extends them. Autopilot for Testers and custom AI agents handle the repetitive, pattern-based work so you can focus on judgment calls: what to test, why it matters, and how to interpret the results. Robots and agents work best together — robots bring determinism and control, agents bring adaptability and reasoning.
    
    That's what this training is about: **building real, reliable test automation, augmented by AI at every step.**
